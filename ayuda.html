1. ¿Qué es este sitio?

Objetivo

Este portal presenta una solución de ciberseguridad y gobernanza digital con enfoque ético, orientada a proteger activos digitales sin invadir la privacidad ni vulnerar derechos básicos del individuo.

Público

Está diseñado para equipos de TI, liderazgo, departamentos de cumplimiento, recursos humanos y organizaciones que buscan una arquitectura de seguridad responsable.

Uso principal

El usuario puede navegar por la landing, revisar políticas y datos, y simular módulos operativos para entender cómo funcionan los controles de seguridad digital.

2. Guía rápida de uso

1. Empieza por el inicio

Revisa el hero y la propuesta principal para entender la intención del producto: seguridad sin invasión y gobernanza responsable.

2. Explora la navegación

Usa la barra superior o el manual para moverte entre servicios, precios, privacidad, compromiso ético y módulos operativos.

3. Prueba un módulo

Haz clic en cualquier módulo de seguridad para ver su demo funcional: auditoría, sesiones, TOTP, privacidad o API keys.

3. Secciones del sitio

  • Inicio: Presenta la propuesta, la identidad y el valor principal del producto.
  • Servicios: Explica las soluciones de red, métricas y auditoría con enfoque de privacidad.
  • Precios Justos: Muestra un modelo de pricing transparente y una calculadora interactiva.
  • Política y Datos: Aclara cómo se gestionan la telemetría, el cifrado y la protección de la información.
  • Compromiso Ético: Desarrolla los principios éticos de la plataforma: explicabilidad, veto a invasión, desconexión digital y transparencia.
  • Acerca de Nosotros: Detalla el propósito de la empresa y la visión del proyecto.
  • Contacto: Presenta canales de comunicación para consultas, soporte o propuestas comerciales.
  • Módulos de seguridad: Agrupa herramientas de auditoría, sesiones, TOTP, RBAC, privacidad, whistleblower, firma digital, dashboard, backup y API keys.

4. Manual de cada módulo

Permite filtrar eventos por fecha y nivel de criticidad. Además, exporta los datos a CSV para análisis legal o de seguridad.

  • Selecciona rango de fechas y nivel.
  • Haz clic en “Filtrar” para ver eventos relevantes.
  • Usa “Exportar CSV” para guardar la evidencia.

Muestra los dispositivos activos y revoca accesos por riesgo o inactividad.

  • Revisa el listado de sesiones vigentes.
  • Haz clic en “Revoke” para cerrar una sesión.
  • Usa “Cerrar inactivas” para aplicar la política de seguridad.

Define reglas de complejidad y genera un secreto TOTP para enrolamiento multifactor.

  • Cambia la longitud mínima y habilita símbolos.
  • Guarda la política de acceso.
  • Genera un secreto TOTP para autenticación de dos factores.

Representa la matriz de permisos por rol y módulo para evitar sobreexposición de accesos.

  • Compara roles como Admin, Auditor y Empleado.
  • Asigna permisos por función.
  • Usa la matriz para mantener la separación de funciones.

Administra consentimiento, exportación y derecho al olvido, sin perder trazabilidad ni control operativo.

  • Alterna el consentimiento de tratamiento.
  • Exporta datos personales en JSON.
  • Aplica anonimización mediante “USER_DELETED_XXXX”.

Permite reportar comportamientos problemáticos sin asociar la denuncia a una sesión o IP visible.

  • Describe la situación.
  • Haz clic en “Enviar Anónimo”.
  • El sistema genera un tracking cifrado para gestión interna.

Genera una firma digital del documento mediante hash SHA-256 para evidenciar integridad y trazabilidad.

  • Edita el texto del contrato.
  • Haz clic en “Firmar contrato”.
  • Se genera la huella digital y el sello temporal.

Agrega una vista resumida para líderes, con indicadores clave sobre usuarios, actividad y volumen.

  • Consulta usuarios activos.
  • Revisa la hora pico.
  • Analiza volumen transaccional y riesgos.

Ejecuta un respaldo de demostración y almacena su evidencia en el log para continuidad de negocio.

  • Define un intervalo.
  • Haz clic en “Respaldar ahora”.
  • Revisa el log para confirmar la operación.

Genera credenciales para integraciones y define permisos mínimos para cada servicio.

  • Escribe un nombre para la integración.
  • Selecciona permisos.
  • Genera la key y usa la salida como credencial demo.

5. Funciones clave del sitio

Navegación

El sistema usa rutas hash para cambiar entre secciones y módulos sin recargar la página completa.

Simulaciones

Los módulos ejecutan acciones de demostración que muestran el flujo técnico y operativo típico de una plataforma de seguridad ética.

Evidencia

Las funciones de auditoría, firma digital y tracking generan registros para demostrar trazabilidad, garantía y cumplimiento.

6. Preguntas frecuentes

  • ¿Puedo usar este manual sin leer la landing? Sí. La ayuda está pensada como guía independiente para entender la plataforma.
  • ¿Los módulos son solo demostrativos? Son simulaciones funcionales, diseñadas para evidenciar el flujo de operación y decisión de seguridad.
  • ¿Dónde encuentro la política legal? En el footer y en las secciones legales del sitio principal.
  • ¿Es una web estática? Sí, funciona de forma directa en HTML, CSS y JavaScript sin depender de backend.
